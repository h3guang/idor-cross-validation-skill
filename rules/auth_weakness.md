# 认证缺陷检测规则（完整版）

## 规则描述
检测认证机制中的安全缺陷，包括暴力破解、枚举、密码重置等。

## 检测项

### 1. 暴力破解防护绕过
- 连续10次错误登录，是否锁定账号
- 是否出现验证码
- 锁定后是否可继续尝试
- 重置后锁定时间是否重置

### 2. 用户名枚举
- 对比存在/不存在用户的响应差异
- 状态码、错误消息、响应时间

### 3. 密码重置漏洞
- 重置链接是否可预测（时间戳/自增ID）
- 是否可绕过身份验证
- 旧密码是否继续有效
- 重置后会话是否失效

### 4. Session固定攻击
- 登录前后SessionID是否变化
- 是否可预置SessionID

### 5. 多因素认证绕过
- 2FA是否可跳过
- 验证码是否可爆破
- 备用码是否泄露

## 判断标准
- 连续失败无锁定
- 用户存在/不存在响应不同
- 重置链接可预测
- SessionID未重新生成

## 测试用例示例
连续10次错误登录
用户名: admin
密码: wrong1, wrong2, ... wrong10

预期: 第5次后锁定或出现验证码
实际: 第10次仍可尝试 → 漏洞确认

## 修复建议
- 登录失败5次后锁定10分钟
- 统一错误响应（不区分存在/不存在）
- 重置令牌使用UUID + 时效性
- 登录后重新生成SessionID
- 2FA强制启用，不可跳过
- 密码复杂度策略（大小写+数字+特殊字符）
